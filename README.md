# design-patterns-dojo
*Ejercicios prácticos de patrones de diseño (GoF) en Java.*  

---

## 🎯 **Objetivo**  
Aprender implementando los 23 patrones de diseño clásicos (GoF) y modernos, con ejemplos claros y casos de uso realistas.  

---

## 🛠️ **Tecnologías**  
- **Lenguaje**: Java 21
- **Herramientas**: IntelliJ IDEA     

---

## 🚀 **Cómo empezar**  
1. Clona el repo:  
   ```bash  
   git clone https://github.com/pabalvrz/design-patterns-dojo
2. Navega a la carpeta del patrón que quieras estudiar.

3. Ejecuta los ejemplos con tu IDE o consola.
